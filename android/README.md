# TECNO & Infinix Sales Assistant — Android app

Phase 2 foundation. Offline-first catalog built from the Phase 1 database; UI in English, Russian and Uzbek.

## Requirements

- JDK 17
- Android SDK: platform 35 (build-tools 34.0.0 auto-provisioned by AGP)
- Gradle 8.9 — use the bundled wrapper (`gradlew.bat`); a standalone install is not required

On this machine the portable toolchain lives at:

- JDK: `C:\Users\admin\android-tools\jdk17\jdk-17.0.21.0.2+1`
- SDK: `C:\Users\admin\android-sdk` (already referenced in `local.properties`)
- Gradle: `C:\Users\admin\android-tools\gradle-8.9`

## Build

```bat
set JAVA_HOME=C:\Users\admin\android-tools\jdk17\jdk-17.0.21.0.2+1
set ANDROID_HOME=C:\Users\admin\android-sdk
gradlew.bat test
gradlew.bat :app:assembleDebug
```

Unit tests live in `core/data/src/test` and validate the bundled seed bundles (41 models with the 19/13/9 TECNO/Infinix/iTel split, GSMArena model codes for 30 of them, Hot 60i 4G/5G variants, 17 service centers with unique ids/codes and support contacts) and the cross-script search normalizer (city, model and brand spellings in Cyrillic and Latin, apostrophes, punctuation, token matching).

`local.properties` already points at the local SDK, so `ANDROID_HOME` is optional when it stays in place. It can also carry `assistantProxyUrl` / `assistantToken` (the file is gitignored); `-PassistantProxyUrl=…` / `-PassistantToken=…` still win when both are present.

APK: `app/build/outputs/apk/debug/app-debug.apk` (~57 MB; debug build, not minified — the release build will shrink it).

Install on a connected phone with USB debugging:

```bat
adb install -r app\build\outputs\apk\debug\app-debug.apk
adb shell am start -n uz.carlcare.salesassistant/.MainActivity
```

## Personal build (not for distribution)

`gradlew.bat :app:assemblePersonal` produces `app-personal.apk` (`uz.carlcare.salesassistant.ext`, label `T-Seller Ext`, version `2.0.6-ext`) that installs alongside the official app. It packages `app/src/personal/assets/products.json` instead of the 41-model seed: the same catalog plus TECNO/Infinix/iTel models that GSMArena lists but the vendor sheet does not contain — everything announced in 2025–2026, all foldables regardless of year (Phantom V Fold/Fold2/V Flip/V Flip2, Zero Flip) and the iTel lineup back to 2025. That file is generated by `docs/tools/build_personal_catalog.py`, which reads the brand listings and product pages, maps the GSMArena spec rows into the app schema, and writes `docs/tools/personal_extras.json` as the audit trail; `--cached-only` rebuilds from already downloaded pages, `--wayback` fills pages GSMArena rate-limits from Internet Archive snapshots (`archived_at` is recorded in `verification`). The current seed holds 107 models — 45 TECNO, 31 Infinix, 31 iTel — verified on a Galaxy S936B (`docs/screenshots/147`–`150`). Spec values are copied from GSMArena as-is, warranty stays empty (vendor data only), and the assistant catalog counts are computed from the seeded data so they stay correct in both builds.

## Structure

```
app/            Navigation, screens, view models, app theme host
core/data/      Room entities/DAO, seed importer, catalog repository, assets/products.json
core/design/    Material 3 theme, brand accents, shared components
```

Product data is imported from the bundled `products.json` into Room on first launch. Screens read only from Room; there is no hardcoded product content in UI code.

Service support data is bundled the same way in `core/data/src/main/assets/service_centers.json` (hotline, email, 17 service centers with address, phones, hours and coordinates, checked 2026-11-05) and seeded into the `service_centers` / `support_info` tables. Source: the official Carlcare Uzbekistan service-center page, which is also shown in the UI.

## Data rules

Every value originates from GSMArena (reference source, checked 2026-11-05). Missing values are absent from the database and must render as “Not verified” — never inferred. Infinix Hot 60i ships as one catalog entry with 4G and 5G variants (both sold in Uzbekistan).
